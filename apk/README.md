安装说明

1. 手机下载 `zhiyuan-13.62.apk`；
2. 允许「安装未知来源应用」；
3. 直接覆盖安装即可，签名一致（CN=ZhiYuan），存档与聊天记录不会丢。

这个版本的改动

- 角色扮演已独立成底栏分页「扮演」，必须填 API（模型接口）才能对话
- 角色扮演：长期记忆（摘要+事实表+自动换卷）、卷列表与回滚、导出/导入、每日自动备份
- 新增「角色扮演」：本机会话 rp:<卡 id>，不进服务器；角色卡 / 世界包 / 上下文预算
  / 流式逐字回话 / 试演一句 / AI 接口双槽位（主对话 + 摘要）
- 修复大退（彻底退出）后再打开要重新登录：启动时有一段代码在读取本地存档前
  就把空状态存了进去，把登录令牌覆盖掉了；现在读档前不写存档，登录状态另存
  一份到手机原生存储，被系统杀进程也不会丢（装好后需重新登录一次）
- 「我的」页按钮收成 5 个折叠分组，展开状态会记住
- 新增「反馈箱」会话：在里面发消息会以私信发给开发者（uid 100002），
  开发者的回信会回到反馈箱；没网时先存本机，连上自动补发
- 全局玻璃增强 + 分层调节（强度 / 模糊倍率 / 卡片层 / 控件层四根滑块）
- 修底栏玻璃边框与果冻动效、修「给 AI 发消息落到公共大厅」、修 AI 头像串成用户头像
- 小米 5 等 360×640 小屏适配（顶栏/底栏收窄、AI 面板按钮吸底）
