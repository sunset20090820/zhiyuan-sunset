安装说明

1. 手机下载 `zhiyuan-13.82.apk`；
2. 允许「安装未知来源应用」；
3. 直接覆盖安装即可，签名一致（CN=ZhiYuan），存档与聊天记录不会丢。

这个版本的改动

- 动效打磨：过渡期临时关毛玻璃、关会话有对称退场、顶栏收起改为 180ms 且头像不重排
- 动画时长统一到 --dur-fast/base/slow 一份 token，JS 不再各自写死
- 支持系统「减少动效」；切到后台自动暂停常驻动画
